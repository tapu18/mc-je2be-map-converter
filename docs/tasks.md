# タスク管理

作業の再開と分担のためのメモ。エージェントは作業の前後にここを読み書きし、変更はコミットに含める。

## 使い方

- 着手時：対象タスクの「担当」に自分の識別名（例：`agent-poc-1`）と日付を書き、状態を `進行中` にしてコミットする。担当がすでに入っているタスクには手を出さない。
- 区切りごと：「作業ログ」に1行追記する（何をしたか、どこまで確かめたか、次の一手）。
- 完了時：完了条件を満たしたことを確認し、状態を `完了`、根拠（テスト名、コミット、ドキュメントの節）を書く。
- 途中で止める場合：状態を `中断` にし、作業ログに再開手順を書く。担当欄は空にする。
- 新しく見つけた作業は「未着手」に追加する。設計の変更が必要なものは `要承認` を付けて人に回す。

状態：`未着手` / `進行中` / `中断` / `完了` / `要承認`
