# マクロの ID 候補調査（途中）

## 再現

固定サーバーと対応表を `npm ci && npm run setup:servers && npm run setup:mappings && npm run build:pack` で用意する。非公開コーパスは元の ZIP のまま読み、抽出結果を公開しない一時領域に置く。

```sh
python3 -I scripts/dump_macro_sources.py /path/to/sample-map > /tmp/macro-sources.jsonl
node tools/trace-macro-ids.ts /tmp/macro-sources.jsonl servers/reports-26.3/reports/commands.json
```

JSONL には関数 ID、storage 名、コマンド本文が含まれる。リポジトリ、Issue、PR、CI の成果物に載せない。不要になったら削除する。出力は集計のみ。抽出は ZIP のワールドと独立パックを対象にし、有効パックや優先順位、overlay を解決しない。同一ワールドの同名関数は区別せず、タグ・動的呼び出しは解決しない。現段階では非対応 ZIP を黙って飛ばす場合があり、完全性を保証しない。

## 暫定結果と未完了

2026-11-25 の非公開コーパスで、3,630 行・4,089 穴、試探失敗 15 行。固定版 26.3 の文法で 6 種の共通置換を試し、いずれかが成功したとき item/block の引数の ID 部分に位置する穴は 2 件。成功例の間で穴のパーサ型が変化した例は 0 件。2 件のうち 1 件は storage のルートを渡す呼び出し、1 件はインライン引数の呼び出しを検出した。storage の穴について単純な直接 `set value` と `merge` 内の文字列候補は 0 件。同じ storage には `merge` と他の操作があるが、実行順や操作の影響は未解決。コマンドや関数の到達可能性は調べていない。

これは網羅数でも、実行時の候補が存在しない証明でもない。有限試探では穴が別の構文として解釈され得る。失敗行、同名関数の上書き、別の呼び出し形式、関数タグ、動的 storage 操作、`merge` や複合値の書き込みは未解決。`matchingWrite` はパスが近い書き込みを機械的に拾った件数で、値候補を意味しない。`literalCandidate` は引数フィールドへの直接 `set value` の単純な文字列、`mergeCandidate` は単純なキーのパスをたどれる `data merge` の文字列を候補とするだけで、実行順や動的な上書きを考慮せず候補集合の完全性を保証しない。

完了には、各穴について可能な構文の範囲を明示し、呼び出しの種別と storage の定数・動的な書き込み、複合値を追跡し、未解決の理由を重複なく集計する必要がある。合成データによるテストを拡張して抽出漏れと公開情報の混入を検証し、結果を #107 に報告する。


## 追加調査（2026-11-25）

同一の入力で、共通置換がすべて失敗した行には、同名の穴に同じ値を使い、6 種の値の組合せを最大 512 通り試した。2 行が解析可能になり、残り 13 行（うち `item` 2 行、`give` 1 行、`execute` 3 行、`summon` 2 行、`tellraw` 3 行、その他または動的なコマンド名 2 行）は未解析。成功した 2 行では全穴を引数に対応付けられた。いずれかの成功例で ID 部分と判定された穴は 2 件のまま。組合せの打ち切り、文法や値の不足、引数以外へ置かれた穴により、未解析行にも ID 穴があり得る。

storage 候補検出に、単純なキーの祖先パスに対する複合 `set value` を追加した。2 件のうち 0 件に、直接文字列・単純な `merge`・祖先複合 `set value` のいずれかの候補を検出した。重複しない未解決分類は、storage 呼び出し未検出 1 件（インライン呼び出しを検出）、同一 storage に書き込みがあるが対応する定数未検出 1 件。後者には `merge` と他の書き込みがあり、複雑なパス、動的な値、別の書き込み形式は未解決。これらの候補は到達可能性や実行順を考慮せず、検出数は実行時の値の完全な集合を示さない。

再開時は残り 13 行の構文と必要な置換を秘匿したまま調べ、関数タグ・別の呼び出し形式・パック優先順位・動的操作を分類する。候補の不足を検証してから #107 に結果を報告し、完了条件と CI を確認する。集計器の `unresolved*` は検出できた ID 穴のみを対象とし、未解析行は含まない。
